# Editors

`vcwl lsp` is a language server (stdin/stdout): it reports compile errors and lint warnings as
you type (unsaved text is compiled, together with the project's entry when the file is part of
it), formats with `vcwl fmt`, and completes keywords, elements and style properties.
`vcwl lint [files]` prints the same warnings on the command line.

Lints (per file; a name counts as used when it appears anywhere else in the file):

| code | warns about |
| --- | --- |
| `unused-fn` | a private function nobody calls (`main` and `test_*` excepted) |
| `unused-component` | a private component other than `App` that is never used |
| `unused-state`, `unused-let` | a component's `state` or `let` that is never read |
| `placeholder` | `lorem ipsum`, `TODO:`, `FIXME`, `asdf` in a string literal |
| `deep-view` | a component nesting elements more than 8 levels deep |

## VS Code

`editors/vscode` is an extension without dependencies: a TextMate grammar and a small client for
`vcwl lsp`. With `vcwl` on your PATH (`cargo install --path .`), package it with
Install it from the VS Code Marketplace (`chteau.vcwl`), or build it with `npx @vscode/vsce package`
and install the `.vsix`, or open the folder and press F5.
`node --test editors/vscode/test.mjs` runs it against the real server with a stand-in for the
editor API (not inside VS Code itself).

## Zed

`editors/zed` is a Zed extension: the tree-sitter grammar in `editors/tree-sitter-vcwl`
(highlighting, brackets, indentation) and `vcwl lsp` as its language server. Install it with
"zed: install dev extension" and pick `editors/zed`; `vcwl` must be on your PATH. Its
`extension.toml` points the grammar at this local repository and a commit; change it to the
public URL once there is one. The extension compiles (`cargo check`), and the grammar parses
every `.vcwl` file of the repository without errors; it has not been tried inside Zed.

The grammar is loose on purpose (tokens and bracketed groups) so unfinished code highlights
without error nodes; `src/parser.c` is generated by `tree-sitter generate` (tree-sitter-cli
0.25) and committed, as tree-sitter grammars do.
